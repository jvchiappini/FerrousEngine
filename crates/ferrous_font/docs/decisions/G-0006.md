# G-0006: the MSDF cell does not grow with the DPI scale

- Status: accepted
- Date: 2026-11-23

## Measurement

`crates/ferrous_font/tests/msdf_dpi.rs` replicates the text shader's coverage
(`msdf_common.wgsl`: median of R/G/B, `screenPxRange = px_range * quad/cell`,
`clamp(px_range * (0.5 - sd) + 0.5)`) and compares a 64-texel cell and a
128-texel cell against a **supersampled** reference: an 8x bake (512 texels) of
the same glyph, at 2.0 (a 24 px Caption em and a 28 px Body em).

| role | cell | mean error | max error |
|---|---|---|---|
| Caption 2.0 | 64 | 0.00057 | 0.1104 |
| Caption 2.0 | 128 | 0.00000 | 0.0000 |
| Body 2.0 | 64 | 0.00060 | 0.1570 |
| Body 2.0 | 128 | 0.00000 | 0.0000 |

One 8-bit step is 0.00392. The 64-cell mean error is **6-7x below one step**;
the max is an isolated pixel where the true edge crosses a corner. A 128 cell
costs 4x the GPU bytes (5.31 -> 21.23 MB for the Latin set) and buys an error
the framebuffer cannot show. The absolute max error also grows with the drawn
glyph (0.070 -> 0.110 for Caption), which is the same *relative* error at a
larger size: MSDF quality is texels per em, not device pixels.

## Decision

The base cell stays at 64 texels (`DEFAULT_GLYPH_SIZE`). It grows only when the
**drawn em** is larger than `GROW_MULTIPLE = 2.0` cells (128 px), because only
then does the field have fewer texels than the em; `cell_for_em`
(`src/scaled.rs`) implements that and clamps to 128.

`ScaledAtlases` (which grew the cell with the scale and kept one per scale) is
replaced by `RasterPolicy`/`cell_for_em`. The `bytes <= fresh_bytes` assertion
is gone: both sides called the same function.

## Icons

The icon cache (`IconAtlas`, `icons.rs`) uses the same MSDF shader and the same
base cell; an icon is drawn at `TypeRole::icon_size * scale` (at most 48 px at
2.0), far under the 128 px threshold, so it follows the same policy and is not
re-rasterized per scale. There is no separate icon pixel harness: the shader
and the cell are identical, and the font measurement above is the same
computation.
