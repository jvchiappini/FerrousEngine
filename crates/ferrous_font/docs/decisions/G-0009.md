# G-0009: runtime lazy fallback and colour emoji are deferred

- Status: accepted, deferred
- Date: 2026-11-23

The screenshot harness resolves fallback glyphs
(`guimaker_gallery/src/shot.rs::story_font`), but the runtime runner still bakes
`latin_western` once (`runner/events.rs:275`); a real app that draws `?` still
gets `.notdef`. Adding glyphs later needs the atlas owned by the runner to be
re-baked and re-bound from the app's frame path (`DrawContext` exposes the font
immutably today). The plan is a `ctx` queue: the app requests extra characters,
the runner re-bakes the composite atlas before the next draw and rebinds
`GuiRenderer::set_font_atlas`. Deferred because it needs a mutable font seam
through `DrawContext`, which is a separate API change.

Colour emoji need an RGBA page and a per-glyph colour flag in `TextQuad`
(56-byte wire format) plus a COLR/CBDT reader; the clapper board is currently
drawn with the monochrome Segoe UI Symbol glyph. Deferred with the page work in
phase 9B.
